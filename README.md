# Memoire IDS Project

Projet de mémoire sur la détection d'anomalies réseau à partir de CICIDS2017.

## Structure
- data/: datasets brutes et traitées
- notebooks/: exploration et expérimentation
- src/: code source
- models/: modèles sauvegardés
- results/: résultats et métriques

## Dataset
CICIDS2017 - MachineLearningCVE
